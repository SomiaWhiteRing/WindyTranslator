# RPG制作大师校对工具 v4.1

面向 RPG Maker 2000/2003 翻译校对工作流，支持 JSON、成对 TXT（原文/译文）和 Excel 表格三种数据源。

## 本版重点更新

### 1. 列筛选：文本列与枚举列分开

右键表头 → “筛选当前列”：

- 原文、译文、说明、文件位置等自由文本列：使用“包含文本”筛选。
- 是/否、状态、置信度、类别、类型、文本侧、是否相符等有限固定值列：弹出复选列表，可多选具体值。
- “清除表格筛选”恢复全部行。

所有“全选/全不选”类按钮只作用于**当前筛选后仍可见且可选择的行**；被筛选隐藏的行不会被新增选择，也不会被取消选择。

### 2. 列表分行显示

格式设置 → “集中一行 / 显示分行”。

显示分行时：

- 最多显示正文 5 行；
- 超过 5 行时额外显示半行级提示，例如 `↕ 还有 3 行`；
- 列表行高会根据**当前表中可见记录所需的最大行数**自动调整，不再固定为三行。

> 技术说明：当前表格基于 Tk/ttk `Treeview`。该控件原生只允许“一张表一个 rowheight”，不能让同一张 Treeview 中每一行拥有不同物理高度。因此本版采用“当前可见记录的最大行数决定本表行高”的方式，避免截断；如果未来必须做到真正逐行不同高度，需要把全部表格控件更换为自定义 Canvas/表格组件，这是一次更大的 UI 架构调整。

### 3. RPG Maker 2000/2003 操作符一览

单独文本处理页新增：

- `RPG Maker 2000/2003 操作符一览`
- `打开中文操作符文档`

操作符窗口显示：

- 操作符；
- 推荐插入形式；
- 中文作用；
- 显示/运行效果；
- 当前原文+译文中使用次数。

双击一行可以把操作符插入译文光标位置。

“隐藏 RPG Maker 通配符/操作符”时：

- 编辑框切换为只读；
- `\C[n]`、`\S[n]`、`\!`、`\.`、`\|` 等不可见控制本身隐藏；
- `\\` 显示其实际生成的反斜杠；
- `\_` 用细空格近似显示；
- `$A`–`$z` 显示近似 Unicode 图形；
- `$r` 等会产生标点的特殊字符，在标点统计中按其**显示结果**统计；
- `\N[n]`、`\V[n]` 属于运行时替换，预览显示占位说明。

随程序附带：

- `资料/RPG_Maker_2000_2003_操作符一览.txt`
- `资料/RPG_Maker_2000_2003_操作符一览.md`
- `资料/RPG_Maker_2000_2003_操作符一览.json`

默认操作符范围只使用 RPG Maker 2000/2003 资料，不把 MV/MZ 的 `\I[n]`、`\{`、`\}`、`\PX[n]`、`\PY[n]`、`\FS[n]` 等扩展混入默认规则。

参考资料：

- YADOT（RPGツクール2000）“制御文字と外字”：http://yado.tk/2k/01_shoshin/010_seigyo_moji/
- Steam Community “RM2k3 Text Codes”：https://steamcommunity.com/sharedfiles/filedetails/?id=2985764828
- RPG Maker Web “Message Box Special codes RPG 2000/2003”：https://forums.rpgmakerweb.com/threads/message-box-special-codes-rpg-2000-2003.117066/

### 4. 引号处理重新分列

“标点符号处理 → 引号处理”现在一条文本固定显示：

- 引号状况；
- 状况与原文相符；
- 引号样式；
- 样式与原文相符；
- 批量处理能力；
- 原文；
- 译文；
- 处理结果。

三类判断列都可以右键筛选。

引号状况与引号样式分开处理：

- **引号状况**负责外层引号是否封闭、只有左引号、是否适合批量处理；
- **引号样式**负责 `「」`、`“”` 等符号风格统一；
- 已有左引号的位置不会被移动到全文最左端；
- 原文同时含多种引号样式时，不允许自动决定统一样式。

### 5. 可编辑标点分类文档

程序实际调用：

`配置/标点符号分类.json`

“批量替换符号”页可直接打开该文件编辑。程序重新扫描时重新读取它。

本版扩充到常见：

- 点号：句号、问号、感叹号、逗号、顿号、分号、冒号；
- 标号：单双引号、括号、书名号、破折号、连接号、省略号、间隔号、分隔号等；
- 常见全角/半角、中文/英文/日文对应形式。

例如 ASCII `!` 现在归类为“点号 / 感叹号（半角）”，不再显示为未分类。

### 6. 省略号检查规则重写

“连续点”现在严格定义为：

- 至少两个；
- **相同的点字符**；
- 连续出现。

因此：

- `.`：不是连续点；
- `..`：连续点；
- `・・・`：连续点；
- `.·`：不是同一种点，不合并成连续点；
- `…`：始终属于省略号，不属于连续点；
- `……`：两个省略号。

检查结果会区分：

- 原文与译文省略号**形式不一致**；
- 原文与译文省略号**数量不一致**。

转换区改为更明确的三种方向：

#### 连续点 → 省略号

- 选择哪些点字符允许转换；
- 每 X 点对应一个省略号；
- 多余点：删除 / 变成一个省略号；
- 目标省略号单位：单省略号 `…` / 双省略号 `……`。

#### 省略号 → 连续点

- 每一个 `…` 对应 X 个点；
- 点字符可选 `.`、`．`、`·`、`・`、`。`。

#### 省略号 → 省略号

- 统一成单省略号；
- 或统一成双省略号。

若连续点中夹有 RPG Maker 操作符，例如 `.\|.`：

- 只有“每 1 点 → 1 个省略号”允许自动处理；
- 操作符保留原位；
- 每 2 点/3 点成组转换会跳过该项。

原文本身存在多种省略号/连续点风格时，标记为手动处理。

### 7. 英文大小写

查询范围改为按**原文大小写模式**筛选：

- 原文大写；
- 原文小写；
- 原文首字母大写；
- 原文大小写混搭；
- 全部。

表格新增：

- 原文大小写格式；
- 译文大小写格式；
- 与原文相符。

新增：

- “查询与原文格式不相符”；
- 全选；
- 全不选。

### 8. 字符全半角

保留原有字符范围：

- english；
- digits；
- both。

新增原文格式筛选：

- 原文半角；
- 原文全角；
- 原文混搭；
- 全部。

两个筛选条件共同生效。表格新增原文/译文格式和“与原文相符”，并提供不相符查询、全选和全不选。

### 9. 辞典导入类别

生成辞典和外部辞典匹配均支持：

- `Original + Translation`
- `原文 + 译文`
- 兼容旧 `Original + Translated`

如果外部辞典没有“类别/Category/Type”列，程序会在导入前弹窗要求为**整份辞典**指定一个默认类别；可选择预设类别，也可自行输入。

生成辞典页新增“全选当前可见行 / 全不选”。

## 运行

Windows 双击：

`启动工具.bat`

首次运行如未安装 openpyxl，会自动安装 requirements.txt 中的依赖。

## 打包 EXE

双击：

`打包EXE.bat`

生成：

`dist/RPG制作大师校对工具.exe`

v4.1 的打包脚本会把 `配置` 和 `资料` 默认文件一并打包。首次运行 EXE 时，默认文件会复制到 EXE 所在目录，之后可以直接打开和修改，不会只存在于 PyInstaller 临时目录。
