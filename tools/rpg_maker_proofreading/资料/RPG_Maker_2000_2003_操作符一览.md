# RPG Maker 2000/2003 消息操作符与特殊字符一览

本表只针对 **RPG Maker 2000 / RPG Maker 2003** 的消息文本，不把 RPG Maker MV/MZ 后来新增的 `\I[n]`、`\{`、`\}`、`\PX[n]`、`\PY[n]`、`\FS[n]` 等操作符混入默认规则。

## 一、消息控制符

| 操作符 | 作用 | 说明 |
|---|---|---|
| `\C[n]` | 改变文字颜色 | `n` 对应系统图的文字颜色编号；2k/2k3 常用 0–19。 |
| `\S[n]` | 设置文字速度 | `n` 为 1–20；1 最快，20 最慢。 |
| `\N[n]` | 显示角色/主人公名称 | `\N[0]` 为当前队伍最前方角色。 |
| `\V[n]` | 显示变量值 | `n` 为变量编号。 |
| `\$` | 显示持有金钱窗口 | 弹出当前金钱窗口。 |
| `\!` | 等待按键 | 文章显示途中暂停，等待玩家确认。 |
| `\.` | 短等待 | 约等待 1/4 秒。 |
| `\|` | 长等待 | 约等待 1 秒。 |
| `\^` | 结束时不等待按键 | 文字显示结束后自动关闭/继续。 |
| `\>` | 开始瞬间显示 | 与 `\<` 配对。 |
| `\<` | 结束瞬间显示 | 结束 `\>` 开始的瞬间显示区间。 |
| `\\` | 显示反斜杠 | 在游戏中显示一个反斜杠。 |
| `\_` | 半个空格 | 插入半格宽度的空白。 |

### 参数嵌套

RM2k/2k3 社区资料确认 `\N[\V[n]]` 可以工作；也有 RM2000 实例使用 `\S[\V[n]]` 动态控制速度。由于这类嵌套属于较进阶用法，校对工具只保护其整体，不主动改写参数。

## 三、校对工具中的处理原则

1. **字符宽度、大小写和全半角处理时，操作符本身不参与变换。**
2. **隐藏操作符时不可编辑**，防止把参数、等待符号或配对符号误删。
3. `$A`–`$z` 中会生成可见符号的代码，在隐藏预览时显示近似字形；例如 `$r` 按“点”显示，因此标点统计可以把其可见结果计入。
4. `\N[n]`、`\V[n]` 的实际内容必须等游戏运行时才能确定，预览只显示“角色名/变量”的占位说明。
5. `\>` 与 `\<` 是配对控制符。翻译时应尽量保持原有区间关系。
6. `\C[n]` 和 `\S[n]` 会影响其后的文本，不能因为“看起来没有字符”而随意删除。

## 四、资料来源与版本边界

- YADOT「制御文字と外字」：明确面向 RPGツクール2000。
- Steam Community「RM2k3 Text Codes」：明确面向 RPG Maker 2003，列出上述消息控制符与 `$A`–`$z` 特殊字符。
- RPG Maker Web 社区的 “Message Box Special codes RPG 2000/2003” 对同一套代码进行了 2k/2k3 范围内的补充讨论。

本工具没有用 MV/MZ 的新增代码来替代 2000/2003 的规则。
