# 工具作者说明

1. 创建 `tools/<id>` 目录，并让目录名与 Manifest 的 `id` 完全一致。
2. 添加 GUI 入口源码和 `manifest.json`。
3. 为需要预填的 GUI 选项增加 `--initial-*` 参数；不传参数时保持原有行为。
4. 将工具独有依赖放入 `vendor/`，不要在启动时安装依赖。
5. 将外部程序、DLL、配置和资料写入相对路径，并在 `resources` 中声明外部资源。
6. 在开发环境运行主程序，确认“小工具”Tab 能发现并启动工具。

同一工具有多个固定启动方式时，使用 `launch_options`；每个选项写出完整参数集，不在工具页面接受自由输入。可选的顶层 `launch_options_label` 用于命名该下拉框。

工具必须使用参数列表启动，不应依赖 shell 变量或当前工作目录之外的隐式路径。
